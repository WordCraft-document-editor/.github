## About WordCraft

WordCraft is an open source text processor built in Rust with a ribbon-style interface that feels immediately familiar to anyone who has written in a classic word processor. WordCraft focuses on the everyday work of drafting, formatting, and saving documents without the noise that builds up in heavier suites.

The WordCraft ribbon interface keeps commands where writers expect them: fonts, paragraph spacing, styles, tables, and page setup sit on the surface instead of hiding in nested menus. Because WordCraft is written in Rust, the editor stays responsive while long documents scroll, sections reflow, and formatting changes apply. This WordCraft document editor is meant for students, office workers, technical writers, and anyone who wants a dependable writing tool that opens quickly and closes cleanly.

WordCraft is also a genuine Rust word processor project rather than a thin shell around another engine. That choice matters for people who care about performance, memory behavior, and long-term maintainability. The result is a WordCraft open source writing environment where the code and the interface both stay understandable. WordCraft text formatting follows the same principle: bold, italic, underline, headings, lists, tables, and alignment work the way a writer expects, with live preview and no surprises on save.
